# 🛒 Olist E-Commerce Performance & Sales Dashboard

An end-to-end Interactive Power BI Dashboard analyzing sales performance, order logistics, customer behavior, and product category distribution for Olist (Brazilian E-Commerce Dataset).

## 🔑 Key Features & Insights
* **Sales & Revenue Tracking:** Detailed breakdown of total sales, total orders, average order value (AOV), and freight costs.
* **Customer & Geolocation Analysis:** Regional analysis of order volumes across Brazilian states and cities.
* **Product Performance:** Top-performing product categories by revenue and order count.
* **Delivery & Logistics Metrics:** Order fulfillment timelines and review score distributions.

---

## 🛠️ Tools & Technologies
* **Power BI Desktop:** Dashboard design, custom visuals, and interactive slicers.
* **Power Query:** Data cleaning, table transformation, and handling null values.
* **DAX (Data Analysis Expressions):** Custom KPI metrics and time-intelligence calculations.
* **Data Modeling:** Star schema architecture mapping customers, orders, items, products, and payments tables.

---

## 📁 Dataset & Files
* The dataset used is the publicly available **Olist E-Commerce Dataset**.
* Includes transactional tables: `customers`, `orders`, `order_items`, `products`, `sellers`, `payments`, and `reviews`.
